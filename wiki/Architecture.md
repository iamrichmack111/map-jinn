# Architecture

- Python standard-library HTTP server
- SQLite local authentication database
- PBKDF2 password hashing
- ArcGIS JavaScript API frontend
- City of Atlanta GIS services for Atlanta-specific geometry
- USA Structures service for national building polygons
- Viewport-bounded national footprint loading to avoid browser overload
- No conventional basemap
- Docker/Compose packaging
- Playwright browser tests and media capture
