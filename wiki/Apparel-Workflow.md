# Apparel workflow

1. Search or select the footprint place you want.
2. Keep building footprints as the dominant layer.
3. Use clean street linework and names only when useful to the design.
4. Add the location name, coordinates, or a custom apparel label.
5. Choose dark or paper mode and adjust footprint opacity/style.
6. Export PNG for the print composition.

Map Jinn 17.4 is intentionally designed to look like geographic artwork rather than a navigation basemap.
